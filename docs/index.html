Como os números são calculados. Média/dia divide os commits por todos os dias do filtro, inclusive os de zero commit — é o ritmo real. Nos dias ativos divide só pelos dias com pelo menos um commit — é a intensidade quando você senta pra codar. A mediana é o dia do meio: metade dos dias ficou abaixo dela. Com zeros no meio ela costuma ser baixa, e isso é informação, não erro. Com o filtro de dias úteis, sábado e domingo somem da conta inteira — inclusive das streaks, que passam a contar dias úteis consecutivos. Commits são atribuídos ao dia no fuso America/Sao_Paulo e contam só o branch padrão de cada repositório (mesma regra do gráfico de contribuições do GitHub).
